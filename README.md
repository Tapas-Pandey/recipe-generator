# 🍽️ Streamlit Recipe Generator

A simple, interactive web app built with **Streamlit** that allows users to search for delicious recipes using either ingredients or recipe names. It fetches real-time data from the **Spoonacular API** and displays detailed cooking instructions, ingredients, preparation time, and more — one recipe at a time with easy navigation.

---

## 🌟 Features

- 🔍 Search recipes by **ingredients** or **recipe name**
- 🧾 View **full recipe details**:
  - Title and Image
  - Ingredients List
  - Cooking Time & Servings
  - HTML-formatted Step-by-step Instructions
- ⏮️ ⏭️ Navigate recipes with **Previous/Next** buttons
- 🔒 Secure Spoonacular API Key using `secrets.toml`
